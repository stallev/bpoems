# Dashboard PRD (Product Requirements Document)

## Overview

Dashboard представляет собой административную панель управления платформой христианской поэзии, предназначенную для пользователей с ролью ADMIN. Dashboard обеспечивает полный контроль над платформой, включая управление пользователями, контентом, категориями и системными настройками.

## Target Users

### Primary Users
- **ADMIN** - Полный доступ ко всем функциям dashboard
- **MODERATOR** - Ограниченный доступ к функциям модерации

### User Roles & Permissions
Согласно `main_prd.md`, роль ADMIN включает все привилегии MODERATOR плюс:
- Управление всеми пользователями и ролями
- Доступ к аналитике платформы
- Постоянные баны пользователей
- Управление системными настройками

## Functional Requirements

### 1. User Management
#### 1.1 User Overview
- **Список всех пользователей** с фильтрацией по ролям, статусу, дате регистрации
- **Поиск пользователей** по имени, email, ID
- **Пагинация** для больших списков
- **Экспорт данных** в CSV/Excel

#### 1.2 User Details
- **Детальная информация** о пользователе (профиль, активность, контент)
- **История активности** (логины, действия, созданный контент)
- **Статистика пользователя** (количество стихов, комментариев, рейтингов)

#### 1.3 Role Management
- **Изменение ролей** пользователей (SUBSCRIBER → AUTHOR → MODERATOR → ADMIN)
- **Массовые операции** с ролями
- **История изменений ролей** с указанием администратора

#### 1.4 Account Status Management
- **Временная приостановка** аккаунтов (SUSPENDED)
- **Постоянный бан** аккаунтов (BANNED)
- **Активация** заблокированных аккаунтов
- **Причины блокировки** и комментарии администратора

### 2. Content Management
#### 2.1 Poem Management
- **Обзор всех стихотворений** с фильтрацией по статусу, автору, категории
- **Модерация контента** (одобрение/отклонение стихотворений)
- **Редактирование метаданных** (категории, теги, описание)
- **Массовые операции** с контентом

#### 2.2 Category Management
- **Создание категорий** с многоязычными названиями
- **Редактирование категорий** (названия, порядок, активность)
- **Удаление категорий** с проверкой связанного контента
- **Импорт/экспорт** категорий

#### 2.3 Tag Management
- **Управление тегами** (создание, редактирование, удаление)
- **Объединение тегов** для устранения дублирования
- **Статистика использования** тегов

### 3. Moderation System
#### 3.1 Content Moderation
- **Очередь модерации** для контента, требующего проверки
- **Быстрые действия** (одобрить/отклонить/отправить на доработку)
- **Комментарии модератора** к отклоненному контенту
- **История модерации** с указанием модератора

#### 3.2 User Reports
- **Система жалоб** на контент и пользователей
- **Обработка жалоб** с возможностью эскалации
- **Автоматические уведомления** о результатах рассмотрения

#### 3.3 Author Role Requests
- **Заявки на роль AUTHOR** от пользователей
- **Рассмотрение заявок** с возможностью одобрения/отклонения
- **Уведомления** пользователей о решении

### 4. Analytics & Reporting
#### 4.1 Platform Analytics
- **Общая статистика** платформы (пользователи, контент, активность)
- **Графики роста** по периодам
- **Топ контента** по просмотрам, лайкам, комментариям
- **Активность пользователей** (регистрации, публикации, взаимодействия)

#### 4.2 Content Analytics
- **Статистика стихотворений** (просмотры, лайки, рейтинги)
- **Анализ категорий** (популярность, распределение контента)
- **Отчеты по тегам** (использование, тренды)

#### 4.3 User Analytics
- **Активность пользователей** по ролям
- **Конверсия** (регистрация → публикация контента)
- **Удержание** пользователей по периодам

### 5. System Settings
#### 5.1 Platform Configuration
- **Основные настройки** платформы
- **Параметры модерации** (автоматическое одобрение для AUTHOR)
- **Настройки уведомлений** и email-рассылок

#### 5.2 Security Settings
- **Настройки аутентификации** (провайдеры, требования к паролям)
- **Логи безопасности** (попытки входа, подозрительная активность)
- **Настройки сессий** (время жизни токенов)

#### 5.3 Content Settings
- **Ограничения контента** (максимальный размер, форматы)
- **Настройки модерации** (автоматические фильтры)
- **Политики контента** (правила сообщества)

## Non-Functional Requirements

### Performance
- **Время загрузки** dashboard < 2 секунд
- **Поддержка** до 10,000 пользователей
- **Оптимизация** для больших объемов данных

### Security
- **Аутентификация** через NextAuth.js
- **Авторизация** на основе ролей
- **Аудит действий** администраторов
- **Защита от CSRF** и XSS атак

### Usability
- **Адаптивный дизайн** для различных устройств
- **Интуитивный интерфейс** с понятной навигацией
- **Горячие клавиши** для частых операций
- **Контекстная помощь** и документация

### Accessibility
- **WCAG 2.1 AA** compliance
- **Поддержка скринридеров**
- **Навигация с клавиатуры**
- **Высокий контраст** для текста

## Technical Requirements

### Architecture
- **FSD (Feature-Sliced Design)** архитектура
- **Next.js 15.4.4** с App Router
- **TypeScript** для типизации
- **Prisma ORM** для работы с базой данных

### State Management
- **Server Components** для статического контента
- **Client Components** для интерактивных элементов
- **React Query** для кэширования данных
- **Zustand** для локального состояния

### Data Fetching
- **Server Actions** для мутаций
- **API Routes** для сложных запросов
- **Real-time обновления** через WebSocket (опционально)

### UI/UX Framework
- **shadcn/ui** компоненты
- **Tailwind CSS** для стилизации
- **Lucide React** для иконок
- **Framer Motion** для анимаций

## User Stories

### Admin User Stories

#### User Management
- **Как ADMIN**, я хочу видеть список всех пользователей, чтобы управлять их ролями и статусами
- **Как ADMIN**, я хочу изменять роли пользователей, чтобы контролировать доступ к функциям платформы
- **Как ADMIN**, я хочу блокировать проблемных пользователей, чтобы поддерживать качество контента

#### Content Management
- **Как ADMIN**, я хочу управлять категориями стихотворений, чтобы организовать контент
- **Как ADMIN**, я хочу модерировать контент, чтобы поддерживать стандарты качества
- **Как ADMIN**, я хочу видеть статистику контента, чтобы понимать популярность тем

#### Analytics
- **Как ADMIN**, я хочу видеть аналитику платформы, чтобы принимать решения о развитии
- **Как ADMIN**, я хочу отслеживать активность пользователей, чтобы оптимизировать вовлеченность
- **Как ADMIN**, я хочу получать отчеты о производительности, чтобы планировать ресурсы

#### System Settings
- **Как ADMIN**, я хочу настраивать параметры платформы, чтобы адаптировать её под потребности
- **Как ADMIN**, я хочу управлять безопасностью, чтобы защищать данные пользователей
- **Как ADMIN**, я хочу настраивать модерацию, чтобы автоматизировать процессы

## Success Metrics

### User Engagement
- **Время, проведенное** в dashboard
- **Количество действий** администратора в день
- **Скорость обработки** заявок и жалоб

### Content Quality
- **Время модерации** контента
- **Количество отклонений** контента
- **Удовлетворенность** пользователей качеством модерации

### Platform Performance
- **Время отклика** dashboard
- **Количество ошибок** в интерфейсе
- **Доступность** системы (uptime)

## Implementation Phases

### Phase 1: Core Dashboard (MVP)
- Базовая структура dashboard с sidebar
- Управление пользователями (просмотр, изменение ролей)
- Управление контентом (просмотр, модерация)
- Базовая аналитика

### Phase 2: Advanced Features
- Расширенная аналитика и отчеты
- Система жалоб и заявок
- Массовые операции
- Экспорт данных

### Phase 3: Optimization
- Real-time уведомления
- Автоматизация процессов
- Расширенные настройки
- Интеграции с внешними сервисами

## Risk Assessment

### Technical Risks
- **Производительность** при большом объеме данных
- **Сложность** реализации real-time функций
- **Безопасность** административных функций

### Business Risks
- **Сложность обучения** администраторов
- **Ошибки модерации** из-за человеческого фактора
- **Нагрузка** на администраторов при росте платформы

### Mitigation Strategies
- **Поэтапная реализация** с тестированием
- **Автоматизация** рутинных процессов
- **Обучение** и документация для администраторов
- **Мониторинг** и алерты для критических операций
