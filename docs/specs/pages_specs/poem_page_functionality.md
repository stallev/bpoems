# Poem Page Functionality Specification

## Overview

Страница стихотворения (`/poems/[slug]`) предоставляет полный функционал для просмотра, взаимодействия и управления контентом. Эта страница является центральным элементом платформы, где пользователи могут читать стихотворения, оставлять комментарии и отзывы, а также взаимодействовать с контентом.

## Core Components

### 1. PoemContent Component
Основной компонент для отображения содержимого стихотворения.

**Функционал:**
- Отображение заголовка стихотворения
- Отображение информации об авторе с возможностью перехода на профиль
- Отображение содержимого стихотворения в формате TiptapJson
- Отображение тегов стихотворения
- Кнопки управления для автора (редактирование, удаление)

**Структура:**
```typescript
interface PoemContentProps {
  poem: PoemWithRelations;
  author: User;
  currentUserId?: string;
}
```

### 2. AuthorInfoContainer Component
Компонент для отображения информации об авторе стихотворения.

**Функционал:**
- Отображение аватара автора
- Отображение имени автора с ссылкой на профиль
- Отображение даты создания стихотворения
- Кнопки управления для автора (удаление стихотворения)

### 3. PoemContentRenderer Component
Компонент для рендеринга содержимого стихотворения в формате TiptapJson.

**Функционал:**
- Поддержка различных типов контента (параграфы, заголовки, списки)
- Поддержка форматирования текста (жирный, курсив, подчеркнутый)
- Поддержка ссылок и изображений
- Адаптивная верстка для различных устройств

## Comment System

### CommentSection Component
Основной компонент для управления комментариями.

**Функционал:**
- Отображение списка комментариев
- Форма добавления нового комментария
- Редактирование существующих комментариев
- Удаление комментариев
- Оптимистичные обновления UI

**Логика работы:**
1. **Инициализация:** Форма добавления комментария скрыта
2. **Добавление:** При клике на кнопку "Добавить комментарий" форма плавно появляется
3. **Редактирование:** При клике на кнопку редактирования комментарий заменяется формой редактирования
4. **Успешное действие:** После успешного добавления/редактирования форма скрывается
5. **Отмена:** При отмене форма скрывается и возвращается исходное состояние

**Структура комментария:**
```typescript
interface Comment {
  id: string;
  content: string;
  poemId: string;
  createdAt: Date;
  author: {
    id: string;
    name: string;
    image: string | null;
  };
}
```

### CommentItem Component
Компонент для отображения отдельного комментария.

**Функционал:**
- Отображение содержимого комментария
- Отображение информации об авторе и дате
- Кнопки редактирования и удаления для автора комментария
- Кнопка "Пожаловаться" для других пользователей
- Замена на форму редактирования при активации режима редактирования

### CommentForm Component
Форма для добавления и редактирования комментариев.

**Функционал:**
- Поле ввода текста комментария
- Валидация на стороне клиента
- Оптимистичные обновления
- Обработка ошибок
- Поддержка отмены действия

### Логика форм комментариев и отзывов

#### Жизненный цикл формы

1. **Начальное состояние**
   - Форма добавления комментария/отзыва изначально отсутствует в DOM
   - Под списком комментариев/отзывов расположена кнопка "Добавить комментарий/отзыв"

2. **Появление формы**
   - При клике на кнопку "Добавить" форма плавно появляется в DOM
   - Используется анимация для мягкого перехода (opacity, scale)
   - Форма занимает место под списком комментариев/отзывов

3. **Добавление контента**
   - Валидация данных на клиенте с помощью Zod
   - Использование Server Actions для отправки данных
   - Применение оптимистичных обновлений через `useOptimistic`

4. **Успешное добавление**
   - После успешного создания контента форма плавно исчезает
   - Удаление формы из DOM
   - Однократное уведомление через toast библиотеку
   - Мгновенное обновление списка комментариев/отзывов

5. **Обработка ошибок**
   - При ошибке форма остается видимой
   - Отображение сообщения об ошибке с помощью toast
   - Сохранение введенных пользователем данных

#### Требования к реализации

- Использование `startTransition` для недублирующихся обновлений
- Предотвращение множественных вызовов toast-уведомлений
- Корректная работа состояний формы независимо от результата операции
- Поддержка accessibility и семантической разметки
- Адаптивный дизайн с плавными переходами

## Review System

### ReviewSection Component
Основной компонент для управления отзывами.

**Функционал:**
- Отображение списка отзывов
- Форма добавления нового отзыва
- Редактирование существующих отзывов
- Удаление отзывов
- Скрытие кнопки добавления, если у пользователя уже есть отзыв
- Оптимистичные обновления UI

**Логика работы:**
1. **Инициализация:** Форма добавления отзыва скрыта
2. **Проверка существования:** Если у пользователя уже есть отзыв, кнопка добавления скрыта
3. **Добавление:** При клике на кнопку "Добавить отзыв" форма плавно появляется
4. **Редактирование:** При клике на кнопку редактирования отзыв заменяется формой редактирования
5. **Успешное действие:** После успешного добавления/редактирования форма скрывается
6. **Отмена:** При отмене форма скрывается и возвращается исходное состояние

**Структура отзыва:**
```typescript
interface Review {
  id: string;
  title?: string;
  content: string;
  rating: number;
  poemId: string;
  createdAt: Date;
  user: {
    id: string;
    name: string;
    image: string | null;
  };
}
```

### ReviewItem Component
Компонент для отображения отдельного отзыва.

**Функционал:**
- Отображение заголовка отзыва (если есть)
- Отображение содержимого отзыва
- Отображение рейтинга в виде звездочек
- Отображение информации об авторе и дате
- Кнопки редактирования и удаления для автора отзыва
- Кнопка "Пожаловаться" для других пользователей
- Замена на форму редактирования при активации режима редактирования

### ReviewForm Component
Форма для добавления и редактирования отзывов.

**Функционал:**
- Поле ввода заголовка отзыва
- Поле ввода содержимого отзыва
- Селектор рейтинга (1-5 звездочек)
- Валидация на стороне клиента
- Оптимистичные обновления
- Обработка ошибок
- Поддержка отмены действия

## User Interaction Features

### Authentication-Based Features
- **Неавторизованные пользователи:** Могут только просматривать контент и жаловаться на него
- **Авторизованные пользователи:** Могут оставлять комментарии и отзывы
- **Авторы контента:** Могут редактировать и удалять свои комментарии/отзывы

### Claim Report System
- Кнопка "Пожаловаться" доступна для всех пользователей
- Модальное окно для ввода причины жалобы
- Автоматическая отправка жалобы модераторам

### Optimistic Updates
- Мгновенное обновление UI при добавлении/редактировании/удалении
- Откат изменений при ошибке
- Плавные анимации переходов

## Responsive Design

### Mobile-First Approach
- Адаптивная верстка для всех компонентов
- Оптимизированные формы для мобильных устройств
- Удобные размеры кнопок для сенсорных экранов

### Breakpoints
- **Mobile:** 320px - 768px
- **Tablet:** 768px - 1024px
- **Desktop:** 1024px+

## Performance Optimizations

### Code Splitting
- Ленивая загрузка компонентов
- Разделение кода по функциональности

### Caching
- Кэширование данных стихотворения
- Оптимистичные обновления для мгновенного отклика

### Bundle Optimization
- Минимизация размера бандла
- Оптимизация изображений

## Accessibility Features

### WCAG 2.1 AA Compliance
- Семантическая разметка HTML
- Правильные ARIA-атрибуты
- Поддержка клавиатурной навигации
- Достаточный контраст цветов

### Screen Reader Support
- Описательные alt-тексты
- Логическая структура заголовков
- Правильные роли элементов

## Error Handling

### Form Validation
- Клиентская валидация с помощью Zod
- Серверная валидация в Server Actions
- Понятные сообщения об ошибках

### Network Errors
- Обработка ошибок сети
- Retry-механизм для критических операций

## Security Features

- Санитизация HTML-контента
- Защита от XSS-атак
- Валидация всех пользовательских данных

### Authorization
- Проверка прав доступа на сервере
- Защита от несанкционированного доступа
- Аудит действий пользователей
